# Тестовые файлы для лабораторной работы 1

Эти файлы можно добавлять в приложение как работы студента для проверки новой схемы:

- `student_zero_stars.cpp` - не проходит базовые тесты, ожидается 0 звезд.
- `student_one_star.cpp` - проходит базовые тесты, но падает на сложных случаях, ожидается 1 звезда.
- `student_two_stars.cpp` - проходит базовые и сложные тесты, но падает на performance-тестах, ожидается 2 звезды.
- `student_three_stars.cpp` - проходит весь набор, ожидается 3 звезды.
- `student_build_error.cpp` - пример ошибки сборки.

Формат первой лабораторной: внутри работы результаты группируются по алгоритмам, а внутри каждого алгоритма идут тесты уровней `Basic`, `Advanced` и `Performance`.
