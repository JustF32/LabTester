# Тестовые файлы для лабораторной работы 3

Эти файлы можно добавлять в приложение как работы студента для проверки хеш-функций и хеш-таблицы.

- `student_one_star.cpp` - проходит простые операции, но использует слабые хеш-функции и таблицу без нормального роста.
- `student_two_stars.cpp` - корректная таблица на линейном списке, проходит сложные случаи, но проваливает эффективность.
- `student_three_stars.cpp` - эффективная таблица с открытой адресацией, tombstone-удалением и rehash.

Группы тестов: `HashFunctions`, `HashDistribution`, `HashTable`. В каждой группе есть уровни `Basic`, `Advanced` и `Performance`.
