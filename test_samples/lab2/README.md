# Тестовые файлы для лабораторной работы 2

Эти файлы можно добавлять в приложение как работы студента для проверки набора по структурам данных.

- `student_zero_stars.cpp` - почти пустая реализация, базовые тесты не проходит.
- `student_one_star.cpp` - проходит простые сценарии, но ломается на росте буферов, крайних вставках списка и дублях в BST.
- `student_two_stars.cpp` - корректно проходит базовые и сложные случаи, но содержит неоптимальные операции: очередь сдвигает массив на каждом `pop`, список ищет хвост при каждом `pushBack`.
- `student_three_stars.cpp` - корректная и эффективная реализация всех структур.
- `student_build_error.cpp` - пример ошибки сборки.

Формат второй лабораторной: результаты группируются по структурам `Stack`, `Queue`, `Deque`, `LinkedList`, `BinarySearchTree`, а внутри каждой группы идут тесты уровней `Basic`, `Advanced` и `Performance`.
